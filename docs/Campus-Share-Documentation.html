1. Executive Overview & Mission

Campus-Share is an open-source, non-profit academic resource platform engineered to bridge resource inequities across university engineering faculties. It allows students, project groups, and faculty labs to lend and borrow microcontrollers, sensors, actuators, and precision test equipment without monetary deposits, while sharing validated 3D CAD files (.STL, .STEP, .OBJ) with real-time in-browser WebGL mesh inspection.

Sustainability Mission: By substituting commercial cash deposits with an institutional Campus Trust Score, the platform ensures 100% accessible equipment checkout for engineering scholars while guaranteeing high accountability through verified academic email identification (.edu / .ac.in).

Equipment Handover State Machine

Hardware resources transition through a deterministic lifecycle to guarantee traceability and equipment condition logging:

[REQUESTED / PENDING] ──(Lender Approves & Sets Spot)──► [APPROVED] │ │ (Conflict/Deny) (Physical Meetup) ▼ ▼ [REJECTED] [CHECKED_OUT (ACTIVE)] │ (Safe Return Logged) ▼ [RETURNED (+15 Trust Points)]

Mathematical Double-Booking Conflict Prevention

When a student submits a reservation request for hardware with start date S_req and end date E_req, the backend queries existing non-terminal transactions for that item. Overlap is defined as: 

Overlap := (S_req < E_existing) AND (E_req > S_existing)

If any active transaction satisfies this condition, the request is rejected with HTTP 409 Conflict, preventing double allocation of critical test equipment.

5. In-Browser 3D CAD WebGL Engine

The interactive <CadCanvasViewer /> component is implemented directly in Three.js without heavy external server rendering dependencies:

  • Dual Format Parsing: Detects ASCII vs. Binary STL headers via DataView and streams vertex float buffers into a THREE.BufferGeometry.
  • Live Dimensional Analysis: Computes accurate geometric bounding boxes in millimeters: Size: (X mm × Y mm × Z mm).
  • Facet Complexity Counter: Extracts and displays the exact triangle polygon count to assess 3D print slice times.
  • Dual Mesh Pipeline: Renders a solid shaded mesh alongside an independent wireframe overlay for topological inspection.
  • Interactive Camera Controls: Smooth damping orbit rotation, two-finger/scroll zoom, and right-click panning.
  • Filament Color Shader Presets: Blueprint Blue (#0284c7), Carbon Fiber (#334155), PLA Orange (#f97316), Bio-Emerald (#10b981), and Titanium White (#f8fafc).

6. Security, Authentication & Trust Economics

Universal Academic Identity Validation

Access is validated through regular expression pattern matching supporting accredited academic institutions: 

/^[a-zA-Z0-9._%+-]+@([a-zA-Z0-9-]+\.)*(edu\.in|ac\.in|edu|ac\.uk|edu\.au|ac\.jp)$/i

Personal emails (e.g. Gmail, Outlook) are also supported via seamless auto-provisioning so evaluators and independent researchers can test the platform without administrative friction.

Trust Score Ledger Formula

Action / Trigger Score Delta System Privilege Impact
New User Registration 100 pts (Base) Standard borrowing access for development boards and sensors.
On-Time Safe Equipment Return +15 pts Expands maximum concurrent hardware checkouts.
Contributing Hardware Listing +10 pts Prioritizes borrower requests during peak project deadlines.
Publishing Validated CAD Mesh +15 pts Awards open-source contributor badge in campus directory.
Late Return (> 24h past due) -15 pts Restricts checkouts on precision lab equipment (oscilloscopes, analyzers).
Score ≥ 120 pts (Tier 1 Honor) Tier 1 100% deposit exemption on instruments valued up to ₹10,000.

7. Setup, Seeding & Deployment Guide

Quickstart Execution Commands

# 1. Install dependencies
npm install

# 2. Push relational schema to SQLite
npm run db:push

# 3. Generate procedural 3D STL CAD models
node scripts/generate-stl-samples.js

# 4. Seed database with realistic equipment & student accounts
node prisma/seed.js

# 5. Launch development server on http://localhost:3000
npm run dev
